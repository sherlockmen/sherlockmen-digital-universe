# sherlockmen-digital-universe
SherlockMen 的交互式 3D 个人主页

纯静态 HTML、CSS 和 JavaScript，字体及 Three.js 随项目提供，无需安装依赖或构建。

本地预览：在仓库目录运行 `python3 -m http.server 4174`，访问 `http://localhost:4174/`。

检查粒子与开场时序：`node scripts/check-galaxy.mjs`。

GitHub Pages 使用 `master` 分支的根目录。线上地址：
https://sherlockmen.github.io/sherlockmen-digital-universe/

第三方许可证见 `vendor/three-LICENSE.txt` 与 `space-grotesk-license.txt`。
